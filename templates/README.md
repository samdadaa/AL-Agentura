# Historische Template-Beispiele

Die Dateien in diesem Root-Verzeichnis sind unversionierte Scaffold-Beispiele. Sie gehören nicht zum ausgelieferten Laufzeitkatalog und werden vom neuen Loader ausdrücklich abgelehnt. Keine automatische Migration oder Anwendung auf Zielprojekte.

Kanonische, validierte Daten liegen seit EXT-002 unter `resources/templates`: `profiles.json`, `al-standard/manifest.json` und `al-modular/manifest.json`. Die dortigen Agenten-Markdown-Dateien sind weiterhin vorbereitete Beispiele für EXT-007 und noch nicht als Dokument-Manifest eingebunden.

Format, Platzhalter und Migration: [Templates](../docs/modules/Templates.md), [ADR 0001](../docs/architecture/adr/0001-template-manifest-contract.md). Es gibt noch keinen Generator oder vollständigen Renderer.
