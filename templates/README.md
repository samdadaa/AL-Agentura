# Templates
Hier liegen später die unveränderlichen Vorlagen für generierte AL-Projekte.
- `al-standard/` — kleine AL-App
- `al-modular/` — modulare AL-App
- `agent-docs/` — gemeinsame Markdown-Vorlagen
Die aktuellen Dateien sind nur erste Beispieldateien; Rendering/Generator ist noch nicht implementiert.
