# Changelog

## 1.0.4 – 2026-11-02

- Removed automatic Microsoft AL: Go! integration, background waiting, persisted order journal and experimental integration command.
- Clarified commands for setting up an already opened AL project and for independently creating a scaffold.
- Preserved safe project inspection, conflict-aware preview, AL project structure and agent-ready Markdown templates.
- Updated README, Marketplace metadata and tests to match the supported manual workflow.
- Added `npm run clean:release` for generated artifacts and outdated VSIX packages.

## Previous releases

Earlier releases experimented with Microsoft AL project handoff. That experimental workflow is no longer supported.
